Dendrophis is a Python-native terminal coding agent built on Textual. Architecture is event-driven with async/await throughout. EventBus decouples UI, session, tools, memory, and subagents.

Entry: `__main__.py` calls `cli.main()`. CLI parses arguments (`--config`, `--model`, `--session`, `--calibrate`, `--list-models`, `--list-sessions`). `main()` initializes `ConfigLoader`, creates root `DendrophisApp`, and runs it. On exit, saves session state.

`DendrophisApp` is Textual root application. Initializes global `EventBus`, creates `Session` via `SessionFactory.create_session()`, and mounts `MainScreen`. Manages screens: `MainScreen`, `DebugLogScreen`, `ApiKeyPromptScreen`, `CalibrationPromptScreen`, `EditConfirmationScreen`, `MemoryViewerScreen`, `ModelSwitcherScreen`, `MultipleChoiceScreen`, `PrimerScreen`, `PythonExecConfirmationScreen`, `SessionPickerScreen`, `SettingsScreen`, `ToolConfirmationScreen`, `WriteConfirmationScreen`. Sidebar panels: `model`, `tokens`, `status`, `speed`, `context`, `temp`, `cost`, `sysinfo`, `mcp`, `cache`, `reason`, `event`, `todo`, `memory_association`, `primer`.

`Session` is composition root. Owns `ContextManager`, `LLMClient`, `SessionStats`, `SkillManager`, `ToolRegistry`, `SessionToolExecutor`, `SessionPersister`, `PrimerManager`, `SubagentExecutor`, `MCPManager`. Orchestrates conversation loop (`send_message()`): appends user message, evaluates context compaction, streams LLM response, executes tool calls, updates context, repeats until completion or max consecutive failures.

`EventBus` thread-safe publish-subscribe system. Uses `RLock` for subscriber list. Priority-ordered handlers via `bisect.insort` and `heapq.merge`. Sync handlers run in `ThreadPoolExecutor`. Async handlers scheduled on event loop. Global access via `get_event_bus()`.

`LLMClient` streams OpenAI-compatible chat via `httpx.AsyncClient` + SSE. `_ProviderContext` computes flags per request (`is_local`, `is_direct_anthropic`, `is_openrouter`, `is_deepinfra`, `use_responses_api`, `use_xml_tools`, `sse_start_mode`). `_sanitize_messages` strips provider-incompatible fields: `tool_calls` for XML mode, `cache_control` for non-Anthropic. DeepInfra validates tool-call and tool-result pairing counts. `_build_payload` supports OpenAI `/chat/completions` and OpenRouter `/responses`. Supports `reasoning_effort`, `prompt_cache_key`, `stop` sequences, `presence_penalty`, `frequency_penalty`. XML mode injects definitions into system prompt; native mode uses OpenAI `tools` schema. MLC false-positive retry mode handles `finish_reason=tool_calls` with reasoning-only output.

`ContextManager` maintains message history, token counts, and turn count. System prompt is first message. Methods: `append_user`, `append_assistant`, `append_tool_result`, `append_file`. File content wrapped in markdown fence with header. `MAX_FILE_BYTES` 200k. Token count synced from API usage metadata. Compaction triggers when `token_pct >= compaction_threshold`. `FileBlockTracker` marks stable files cacheable after N turns. `UnderstandingPhaseDetector` establishes project understanding checkpoints.

Tool Subsystem: Abstract `BaseTool` defines `name`, `description`, `parameters`, `execute()`, and `schema`. Dynamic discovery via `discover_tool_classes` and `resolve_dependencies_and_instantiate`. Built-in tools: `GlobTool`, `ReadTool`, `RipgrepTool`, `EditTool`, `WriteTool`, `PatchTool`, `BashTool`, `PythonExecTool`, `FunctionAnalyzer`, `TodoManager`. Interactive variants (`InteractiveBaseTool`) present confirmation prompts for destructive actions (`edit`, `write`, `patch`). Memory tools (`SaveMemoryTool`, `SearchMemoryTool`, `RecallMemory`, `DeleteMemoryTool`). Interaction tools (`AskMultipleChoiceTool`). MCP tools integrated dynamically via `MCPManager` and `MCPTool`.

Subagent Subsystem: `SubagentRegistry` manages agent definitions (`AgentDefinition`), spec files (`subagents/specs/`), handlers (`subagents/handlers/`), and dynamic subagents. Built-in roles: `researcher`, `planner`, `code-writer`, `code-reviewer`, `test-runner`, `debugger`. Subagent tools: `InvokeSubagentTool`, `DefineSubagentTool`, `SendMessageTool`, `ManageSubagentsTool`. `SubagentExecutor` runs background agent tasks with isolated/inherited context.

Config & Permissions: Pydantic v2 schema (`LLMConfig`, `CachingConfig`, `PermissionsConfig`, `BashConfig`). `ConfigLoader` uses `ruamel.yaml` for round-trip YAML loading with environment variable overrides (`DENDROPHIS_API_KEY`, `BASE_URL`, `MODEL`). `PermissionPolicy` evaluates tool calls (`ALLOW`, `DENY`, `CONFIRM`) with `BashSandbox` category simulation.

Memory & Persistence: `MemoryStore` uses SQLite with WAL mode (`memories`, `tags`, `tag_memories`) and float32 BLOB embeddings for vector search. `SessionPersister` handles session state serialization/deserialization. `SkillManager` loads `.md` skill files with YAML frontmatter.

Project Layout & Scripts: Root contains launcher `dendrophis.sh`, `CONTRIBUTING.md`, `CLAUDE.md`, `AGENTS.md`. `scripts/launchers/` contains `jit-dend.sh` and `pypy-dend.sh`. `scripts/servers/` contains local AI server scripts (`start_mlx_server.sh`, `start_mlc_server.sh`, `convert_to_mlc.sh`). `benchmarks/` contains benchmark suites (`benchmark_interpreters.py`, `micro_bench.py`, `benchmark_omlx_mtp.py`). `examples/` contains usage demos (`complex_demo.sh`, `event_bus_demo.py`, `simple_demo.py`).
